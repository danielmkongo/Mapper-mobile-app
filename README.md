# Mapper mobile app

Android app (.NET MAUI, .NET 8) for Mapper indoor tracking. It opens the live console of the deployed hub (http://45.79.206.183:7000/): the 3D digital twin, people and alerts.

The hub and twin are in their own repo: https://github.com/danielmkongo/mapper-hub

Build and run: open `safe.sln` in Visual Studio 2022 and run on an Android device or emulator.
